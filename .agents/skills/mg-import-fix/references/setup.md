# 初始化操作细节

主流程和 Gate 以 [执行工作流](workflow.md) 为准。准备图片前读本文件；图片在完整新测试集流程中为必需阶段，无需另行确认。

## 创建 Figma 文件与导入

团队选择遵循 [主工作流的团队规则](workflow.md#figma-团队选择)。本任务的目的包括 MCP 读取，创建后仍须实际读取文件核验权限，不把非 Free 名称当作权限保证。

先加载当前环境的 `figma:figma-create-new-file` 技能，遵守新建文件工具要求；通过 Computer Use 打开 Figma 并新建或进入本次新建的 Design 文件，不重复创建。不要求关闭已有标签页，不修改其他文件。以本批次原生 `.mg` 的文件名去掉扩展名命名，记录链接和 file key。

通过 Computer Use 运行 ReceiveFromMasterGo（界面实测为 MasterGo Importer），遵守[插件运行隔离](workflow.md#插件运行隔离)。先记录页列表，单独导入 `.mg` 的唯一 Page，待插件明确成功并关闭后，重新列页、识别新增页并命名 `<源 Page 名>_mg`。重新启动插件，在实验室启用 ZIP 导入，再单独导入配对 ZIP，按相同步骤确认成功并命名 `<源 Page 名>_zip`。不要使用多文件合并入口。保留导入警告和差异，仅清理本次新建文件自带且确认空白的默认页。

记录根图层名称、顺序、源 ID、位置、尺寸和变换，重复名称用 ID、顺序与几何共同匹配。源非空而导入页为空或导入未完成，不得进入完成状态。

### 已验证的操作经验（2026-09-19 试跑）

- 仓库接收端目录名为 `ReceiveFromMasterGo`，Figma 中实测显示为 **MasterGo Importer**。使用 `Command+K` 搜索此名称，选中正确结果后按 `Return` 启动；仅点击搜索结果曾未启动，必须以插件面板出现为成功依据。以后界面名称变化时按实际入口核实。
- 原生文件选择器：先打开并观察对话框，再按 `Command+Shift+G`，填入本次文件绝对路径，按 `Return` 跳转；观察定位完成后再按 `Return` 确认打开。不要把打开对话框和路径快捷键抢在同一未就绪状态中发送。
- 插件按钮或系统对话框的 AX 点击没有生效时，实测可通过 `Tab` 聚焦目标、`Return` 激活。先核实焦点和标签，再发送按键；界面状态改变后重新读取，不复用旧索引。
- MasterGo 原生 PNG 文件导出成功过，但 Figma “置入图片”选择完文件后仍需要画布放置，不能把文件选择器关闭当作图片已导入。此经验仅验证原生导出，不代表“置入图片”全流程成功；首选流程见下文。

### 已验证的原生 MG 保存与插件焦点恢复（2026-10-01）

- 在设计文件左上角的 MasterGo 主菜单中选「文件 → 保存本地文件」；macOS 顶部「文件」菜单没有这一入口。等待导出完成并出现原生保存框。
- 批次目录已在 Downloads 创建且保存框能列出它时，优先对该目录项执行 AX 提供的 `Open Finder item`。核实 `Where` 已变为本批次目录，保留 `.mg` 文件名后点击 Save；随后用文件系统检查目标文件非空。此路径无需输入中文绝对路径。
- 必须用「前往文件夹」时，先发送快捷键并读取状态，确认路径框已出现，再输入、读取并核对完整路径，最后确认。不要将打开路径框、输入和确认抢在同一未就绪状态中执行；若输入被截断，优先使用当前可见目录导航，不能将错误路径直接确认。
- SendToFigma 首次说明关闭后，若 iframe 的 AX 内容暂时为空，本次用一次 Tab 将焦点移入插件后恢复了完整控件树。重新读取页面勾选与导出按钮后操作，不复用消失前的控件索引。
- 工作区恢复属于新状态：重新核实源文件、唯一 Page、保存框、插件与批次资产是否仍存在；已消失的目录和未落盘资产不能沿用为成功。后续重试以新证据为依据。

## 原生图片基准（必需）

进入图片阶段读取 [原生图片采集、替换与恢复](images.md)，按根层保存 PNG，Duplicate `_zip` 后逐层替换。该文档维护剪贴板脚本用法、键盘遍历、几何证据与例外标准。

## UI 故障恢复

等待、截图异常和前台唤起统一按[桌面状态恢复](workflow.md#桌面状态恢复)执行；不要将首次 AX 未变化当成导入失败。保持现有窗口大小与布局；`noWindowsAvailable` 不以反复切换全屏解决，确需调整窗口时记录并恢复。

失败后先检查插件是否仍在运行或已创建页面，再续作。仅清理确认属于本轮失败的残留，不盲目重复建文件、重复置图。缺插件或权限时报告阻塞，不自行扩大为安装插件。若使用 Playwright，结束时关闭本次验证创建的命名会话，保留目标设计文件和下载资产。

### 菜单与图层树操作经验

方向键可能移动当前设计图层，不能作为展开 Web 右键子菜单或图层树的通用手段。使用实际可见的展开箭头、受支持的辅助功能动作；同一菜单无变化时换用原生导出等明确入口。误触及临时导出设置按[源快照保护](images.md#源快照保护)记录和核验，不盲目连按 Undo。
