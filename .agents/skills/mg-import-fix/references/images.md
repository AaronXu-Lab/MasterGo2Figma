# 原生图片采集、替换与恢复

阶段与 Gate 以 [执行工作流](workflow.md) 为准。本文件仅在准备或恢复图片基准时读取。使用原生视口、主体阴影边距或原生 SVG 边界核验位置；覆盖、几何与用户效果验收是三个不同结论。

## 准备与脚本

建立 `source-roots.json`：按源 Page 直接子节点顺序记录序号、源 ID（可获取时）、名称、x/y、逻辑宽高、旋转/变换；关联 ZIP/MG 根层。重复名称必须结合 ID、序号及几何识别。源快照保持不变。

脚本 [clipboard_image.py](../scripts/clipboard_image.py) 仅处理剪贴板与本地 PNG，不操控桌面，也无法证明图片属于哪个窗口或图层。沿用用户已授权的 Python 剪贴板读写；快捷键与 UI 核验通过当前 Computer Use 工具执行。新建隔离 Python 环境或复用已核实环境，不把临时 venv 路径写死：

```sh
python3 -m venv /tmp/mg-clipboard-env
/tmp/mg-clipboard-env/bin/python -m pip install pyobjc-framework-Cocoa Pillow
. /tmp/mg-clipboard-env/bin/activate
# 命令从仓库根执行；复用环境时换成实际解释器。
python .agents/skills/mg-import-fix/scripts/clipboard_image.py status
python .agents/skills/mg-import-fix/scripts/clipboard_image.py save "$batch_dir/images/001.png" --after-count "$before_copy" --expected-count "$after_copy"
python .agents/skills/mg-import-fix/scripts/clipboard_image.py load "$batch_dir/images/001.png"
```

`batch_dir` 是已核实的本批次绝对路径；计数取自每次复制前后的 `status`，不要照抄旧值。脚本优先原生 PNG，无 PNG 时将 TIFF 用 Pillow 转成 PNG，保留透明度；`save` 使用 exclusive create，拒绝覆盖。`load` 只接受有效 PNG，写入 `NSPasteboardTypePNG` 后逐字节读回核验。JSON 输出含尺寸、SHA-256、changeCount；失败返回非零。`--after-count` 拒绝未更新的剪贴板，`--expected-count` 防止核实后又发生变化；计数变化本身不能证明复制成功，不要求每次恰好增加 1。

## 1. MasterGo 逐层采集

1. 核实源文件、唯一 Page 和实际前台窗口。在画布 `Command+A`、`Option+L` 收起所有图层，定位首个根层一次。每批先验证遍历方向：已实测 `Shift+Tab` 沿 source-roots 正序、`Tab` 反向，不能当成所有文档的固定规律。
2. 核实当前选区与清单中的 ID/名称/序号，记录复制前 `status`。用 `Command+Shift+C` 复制为图片，等待成功，再读 `status`，核实窗口与选区未变；调用一次 `save`，保存为 `001.png` 等稳定序号文件。核对尺寸、哈希与图像内容，将成功结果连同源身份写入 `images/capture.jsonl`。同时比较 PNG 自然尺寸与源逻辑框，将尺寸不符、旋转或外溢层加入几何待核验清单，标明已有证据和下一项最小取证需求。
3. 确认当前项落盘才移动到下一根层，每步重新核验实际选区。正常遍历不逐层搜索名称，也不盲发连续快捷键。仅检查窗口或选区不能由脚本代替。

复制失败、选区不符、非目标窗口或计数异常时立即停批并按下文恢复；不用监听任意 changeCount 变化自动递增编号，不启动不必要的常驻 watcher。

## 2. Figma 逐层替换

1. 采集后 Duplicate `_zip` 页面为 `_image`，核实副本的根层数与顺序，记录副本 ID 映射，保留原始 MG/ZIP 页。若 ZIP 缺层，先记录对应缺口并修复映射，不能静默改用其他页。收起副本图层，定位首层并验证 Tab/Shift+Tab 方向。
2. 对目标序号运行 `load`，核对路径、尺寸与哈希，读回成功才继续。在桌面核实实际 `_image` 页面与唯一对应根层，发送 `Command+Shift+R` 替换粘贴。MCP 改 page/selection 不保证桌面跟随，不能只凭 MCP 选择结果发送快捷键。
3. 通过真实树检查新节点是 IMAGE 填充矩形、无可编辑后代，恢复源名称，记录新 ID 和根层序号。替换后选中的是新图片；已实测可接着 `Shift+Tab` 到下一原根层，但每次仍核验 ID/名称/序号。页面更新后重新列页 ID，遵守 `figma:figma-use` 调用要求。
4. 核对每张图片保持自然像素尺寸、未意外缩放；核验内容、顺序及已有几何证据；边界待查时记录后继续其他层，不能标为几何完成。源中已烘焙的旋转不能再次施加到图片矩形。

不默认使用 Preview 新建/保存，不在空白页普通粘贴，不用 Place all 后自动排布代替上述流程。

## 3. 几何与完成证据

替换粘贴只建立替换关系，不能保证 x/y 不变。原层 END/CENTER constraints 会根据新图片尺寸移动它；ZIP 字体差异也会改变逻辑框。以 MasterGo 源几何和原生渲染边界为依据，不移动 MG/ZIP 比较页来制造一致。

阴影、描边、旋转、字形裁切会使 PNG 大于或小于逻辑框。保持 PNG 自然尺寸，不拉伸到 ZIP 或源逻辑宽高。只有导出边界有证据时才校正偏移：例如不透明主体 bbox 确实等于未旋转源逻辑框时，可用 `image.x = source.x - bbox.left`、`image.y = source.y - bbox.top`；不能把非透明 bbox 一概视为逻辑框。某批实测边距不能成为通用常量。文字和复杂组、旋转、非 1× 图片须单独核实边界/比例，无法确认就记录待核验，不能猜测。

边界仍不清楚时，可用同一快照的 **MasterGo 原生 SVG 导出作为几何证据**：文字检查字形路径紧框，旋转文字检查局部字形框四角变换；复杂组以可识别子层的 SVG 坐标减去源坐标，至少用两个锚点交叉验证边距。核对计算出的范围与 PNG 自然尺寸及实际内容吻合，保留 SVG、源 ID、计算方式和结果；先核实 SVG 路径的坐标系、父级变换与裁切/效果，字形局部紧框的四角变换并非任意 SVG 的最终渲染边界。不要直接用 viewBox、ZIP 文字框、非透明 bbox 或模板匹配分数强行对齐。旋转已烘焙时图片 rotation 保持 0。原生全页 PNG 的整像素匹配可辅助排查，但不能覆盖已确认的子像素几何。SVG 渐变等格式自身也可能有导出差异，相关属性另行核验。

仅对未解决边界按需导出原生 SVG/PNG，同快照且身份可靠的已验证证据可复用；不默认全量导出多套文件。确需同类批量取证时只选择有关根层，核实数量与格式并另存证据目录。关闭源端前检查待取证清单，避免仅完成替换就关闭后又重复打开。

### 源快照保护

不使用方向键试探 Web 子菜单，优先可见箭头或公开控件，避免按键落到画布移动选区。临时导出设置操作前记录设置及所涉节点几何，逐项记录新增/修改操作；恢复后读回设置、x/y、尺寸和变换，不能仅凭 Undo 次数认定已恢复。

发现意外编辑立即停批，核实并恢复该操作、读回几何；将受影响的新证据标为无效并说明范围，恢复后另存取证版本。保留未受影响且已有依据的证据，原始 MG/ZIP/PNG 不覆盖。剪贴板 PNG 与另一次原生导出可能有抗锯齿或一级色值舍入差异；哈希不同比较尺寸、像素变化区域及图层几何后再判断是否源变化，不能仅凭哈希下结论。

### 记录与交付

在 `image-manifest.json` 维护每根层的 sourceId、序号/名称、源几何、PNG 路径/尺寸/哈希、替换后 Figma ID/几何、验证状态及偏移证据；同步 `progress.md`。交付明确区分：

- **覆盖**：源根层数、已保存 PNG 数、已替换图片数、剩余可编辑后代数，以及缺图或隐藏/零尺寸等例外。
- **几何**：逐层核验位置、尺寸、变换、顺序；已知对应逻辑框允许 0.015 浮点误差，实际查看对应区域，确认无意外裁切/缩放/漂移。
- **用户验收**：记录用户是否明确接受效果；覆盖或几何通过不代替用户意见，用户结束流程也不等于全部效果通过。
- **例外**：哪些覆盖缺失、哪些原生边界仍待核验，原因及后续证据需求。覆盖完成不得写成全页像素对齐完成。

## 回退与断点恢复

快捷键无响应或桌面状态异常时，先按[桌面状态恢复](workflow.md#桌面状态恢复)唤起应用，重新核实文件、选区和剪贴板后再重试；状态已可靠但复制仍失败，则使用 MasterGo 原生图层 PNG 导出（优先 1×、透明背景）保存到相同序号体系，再尽可能沿用 load/替换路径。必要的手动放置须逐层恢复对应关系与实际边界；不可用自动排列代替。记录并恢复临时导出设置。任何路径都不能用 Figma 导出、截图、解码渲染替代 MasterGo 原生图片。

停批后从最后一条已核实记录恢复：重新检查源快照、文件/页、实际选区、清单与 PNG 哈希，重新验证键盘方向。不依据当前文件数直接推断下一序号；已有文件仅在身份/哈希匹配时复用，错误或身份不明文件保留并标为无效，另存版本化路径，不覆盖。若替换已发生但记录中断，先读真实树补齐映射，不能对下一层重复替换。

用户切换窗口或恢复/清理工作区后，重新核实磁盘资产、插件与当前页 ID；已丢失的文件需重采集，源已变化则重建配对快照与基准。无法核实身份或边界时保留产物与具体未完成项；按主流程继续可独立工作，图片阶段不新增用户授权 Gate。

维护脚本后使用已安装 Pillow 的解释器运行离线行为测试，不读取或改写真实系统剪贴板：

```sh
python -B -m unittest discover -s .agents/skills/mg-import-fix/scripts/tests -v
```
